# Roadmap

## 0.3 trust foundation

- versioned deterministic rules;
- stdio and Streamable HTTP discovery;
- OAuth metadata audit and private-network controls;
- verified Docker adapter and explicit behavioral exercise;
- public benchmark, coverage, mutation testing, SARIF, SBOM, and provenance;
- public governance and threat model.

## 0.4 ecosystem validation

- external MCP conformance-suite integration;
- larger community-reviewed corpus;
- signed suppression files with expiry and rationale;
- policy packs for CI, local development, and registries;
- structured machine-readable rule documentation.

## 0.5 isolation research

- independently reviewed Windows Sandbox adapter;
- hardened Linux adapter with explicit egress policy;
- macOS isolation feasibility study;
- adversarial fixtures for DNS rebinding, pagination bombs, and transport state recovery.

Roadmap items are proposals, not compatibility commitments. Security invariants take
precedence over schedule.
